# BRP UGE v1.21.11-rc.6 — Clickable Specialty choices / Wizard header repair

## Why this prerelease

User screenshot of RC5 confirms Wizard loaded 20 approved GM specialties and Art has 11 entries, yet its secondary native Specialty select never opened when clicked. The same screenshot shows overlapping occupation summary/budget/progress bars at the top of step 4.

## Fix

- Replace the secondary native Specialty selects with visible radio-button option grids, generated by Handlebars from the *same World Specialty Registry* already proven to contain Art (11). This eliminates dependence on browser/Foundry select-menu opening behavior.
- Personal and Occupation selections both use real clickable radio inputs. Changing Family shows the corresponding radio grid; selection is saved in the Wizard draft and preserved on re-render.
- The Skill Family selector itself remains a native select (it was working). The Add Skill action reads the checked Specialty radio and constructs the matching family|specialty identity.
- Remove conflicting `position: sticky` behavior on step-4 progress and budget bars. Give budget, linked occupation skills, and step progress normal document flow.
- README prominently declares this is a personal-use hobby project developed with assistance from ChatGPT (OpenAI), not an official or endorsed product, in Thai and English.

## Test in a copied Foundry v14 World

1. Install the v1.21.11-rc.6 preview with the separately updated RC5 Compendium (Skill Family Templates). Verify the Game System version in Setup; clear browser cache/reload app after upgrade.
2. Open Character Creation Wizard → Step 4. Check no occupation, allocation or progress bars overlap at the top; scroll from the start of step 4 to the allocation table.
3. Choose Skill Family Art / ศิลปะ. Below the selector, you should see a visible grid/list with all 11 approved Specialties (e.g. Writing / Songwriting); click any option and verify the selected radio state.
4. Click Add Skill. The new Actor-local Art (Writing) Skill should appear in the allocation list. Spend Personal points, return to Step 4, and confirm these points remain intact.
5. Choose an Occupation with an Art Family choice. Select Art then choose a Specialty via its radio grid; confirm the choice is eligible for Occupation points.
6. Change to Dark theme and English UI, confirm the labels and selection visuals remain readable. Keyboard: Tab → Space should select a Specialty.
7. Change GM World options while Wizard is open; click Reload Specialties if necessary, confirm the new choices appear and already allocated points are not reset.
8. Check README on the GitHub repository branch for the Thai/English personal project and ChatGPT disclosure.
