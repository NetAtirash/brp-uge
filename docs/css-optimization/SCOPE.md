# BRP UGE — Core CSS Optimization Only

**Scope frozen by project owner on 2026-11-26.**

- **Do not** develop or merge any visual redesign. Draft UI2 PRs [#9](https://github.com/NetAtirash/brp-uge/pull/9) through [#13](https://github.com/NetAtirash/brp-uge/pull/13) were **closed without merging**; their historical feature-branch commits are not approved designs and are excluded from this branch.
- Work directly from `main` stable BRP UGE `v1.21.11`. This branch changes CSS **delivery and compiler workflow only** and retains all authored source CSS, rules, Actor/Item schemas, Foundry templates, calculations, Compendium separation and all existing appearance.
- **Measured baseline:** 19 separate CSS resources loaded by `system.json`. Source order is captured in [css-sources.json](../../scripts/css-sources.json). The existing CSS has many historical priority rules; do not strip them without verified cascade and real Foundry browser testing.
- Compile one minified CSS file with a **pinned, dev-only** Lightning CSS compiler while preserving source file order and same `styles/` directory as relative `../assets/` URLs.
- Provide deterministic source validation, mandatory CSS integrity and all legacy regressions, generated `BEFORE_AFTER.json`/`BEFORE_AFTER.md` with byte/compression/request metrics, and a package integrity check.
- **No merge to main, no release, no next phase without the user's explicit approval.** The output is a reviewable Draft PR on this branch, not a claim of live Foundry visual parity.
- Browser check required before approval: Light/Dark, Thai/EN, Character/NPC/Item/Wizard/Chat, CSS URLs, font imports, no missing images, no regressions in scroll or layout. Source-level tests and size metrics do not establish actual Foundry render parity.
- The original 19 source files remain untouched in Git, so a rollback consists of restoring the original manifest CSS paths; no Actor data is migrated.

**Optimization limitations:** Bundling/minification reduces CSS resources and transfer bytes; it does NOT by itself remove all legacy selector specificity, cascade interactions, or runtime DOM reflow bottlenecks. Those require separate profiling and approval. Do not report full architectural CSS cleanup or faster frames without real measurements.
