# RC.6 — Specialty integrity and localization: release candidate gate

Reference: Chaosium Basic Roleplaying ORC Content Document, Chapter 3 Skills (pp. 32–34 summary; pp. 44–45 Literacy/Martial Arts; pp. 50–51 Status). https://www.chaosium.com/content/orclicense/BasicRoleplaying-ORC-Content-Document.pdf

Coverage review checklist (not runtime content):
- Combat: Artillery, Energy Weapon, Firearm, Heavy Weapon, Martial Arts, Melee Weapon, Missile Weapon; Parry when using the separate parry rule.
- Communication: Etiquette, Language, Perform, Status.
- Manipulation: Art, Craft, Heavy Machine, Repair.
- Mental: Knowledge, Literacy (optional), Science, Technical Skill.
- Physical: Drive, Pilot, Ride.
- Check Fly separately: the ORC text describes flight-mode-dependent base chance, not a list of specialties; do not infer a Family merely from alternate formulas. Shield is not automatically specialized by shield model.

The list above is a QA baseline, not a certification of the installed pack; content maintainers must check the full printed edition and optional rule distinctions. No book option records are bundled.

Game System changes: source provenance deduplication for copied World items/packs, explicit independent-template conflicts, rejected/empty/default diagnostics, pack read errors, stable book-key aliases, reputation advancement guards, shared dynamic base formulas, settings presentation map covering registered visible settings/menus/choices. The GM's data and Actor documents are not migrated or reset.

Open release gates: receive the complete corrected Compendium ZIP, inspect the actual packed skill data and cross-references, validate each Family and all Personality/Occupation templates using the read-only audit against live documents; assess modern Literacy total-link policy (the LANGUAGE_BASE formula is base only); test Foundry v14 in both languages and themes. Do not claim the Critical content problem is resolved or publish RC.6 until matching package and owner approval. Stable, main and the testing manifest remain unchanged during candidate development. Full package replacement only.
